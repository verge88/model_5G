# Проверка фальсификации нагрузки SMF на Open5GS

Реальный изолированный стенд: Open5GS v2.8.0, UERANSIM v3.2.7 с исправлением
CLI, 3 SMF, 1 AMF, 1 NRF, 1 SCP, 1 UPF и необходимые AUSF/UDM/UDR/PCF/NSSF/BSF.
Prometheus собирает контрольные метрики. Порты контейнеров не публикуются.

## Подтверждённое до основной серии

- B0: три прогона по 300 успешных PDU-сессий. Все 300 назначались первому
  зарегистрированному SMF; порядок регистрации менялся 123 → 231 → 312.
- Исходный NRF игнорирует PATCH `/load`; исправленный сохраняет значение и
  отклоняет нецелые значения, строки, null, bool и значения вне [0,100].
- Работает полная цепочка SMF → NRF → свежий discovery AMF → выбор SMF.
- SCP учитывает успешные CreateSMContext, Release и уведомления RELEASED.
- Версии отчётов передаются диагностическими HTTP-заголовками; стандартное
  JSON-тело heartbeat не расширяется. Версии используются только для измерений.

Текст статьи — `article/ARTICLE.md`, PDF — `output/pdf/SMF_Load_Veracity.pdf`.
Полный статус выполнения и ограничения — `article/STATUS.md`.
Журналы контроллеров находятся в `results/article*/matrix.json`;
первоначальный контроллер после остановок продолжен отдельными контроллерами.
`complete` отдельного запуска означает техническое завершение, а научная
пригодность требует сверки с независимыми журналами и контрольными метриками.
Старые `preflight` — отладочные прогоны, не датасет статьи.

## Воспроизведение

```text
docker compose -p model5g-paper build
docker compose -p model5g-paper up -d
docker compose -p model5g-paper exec lab python scripts/test_nrf.py
docker compose -p model5g-paper exec lab python scripts/run_lab.py --out runs/my-check --active 60 --ues 72 --cycles 100 --alpha .5 --interval .01
docker compose -p model5g-paper exec lab python scripts/analyze.py /work/runs/my-check
docker compose -p model5g-paper stop
```

Для воспроизведения изменений используются **целые патчи из `patches/`**.
Их применение к чистым исходникам и совпадение с измерявшимся кодом проверены
в `results/reproducibility.json`. Исходная и изменённая сборки скомпилированы
и проверены реальными сессиями; новый Dockerfile целиком с нуля не прогонялся.
Скрипты `patch_open5gs.py`, `patch_load_version.py`, `patch_transport_trace.py`
сохранены как история разработки; не запускайте их поверх готового дерева.
`patch_load_version.py` — альтернативный, неиспользованный вариант с расширением
JSON Patch. Измеряемая сборка использует вариант HTTP-заголовков.

## Методические границы

`capacity` NFProfile — относительный вес; `C_abs=100` — экспериментальная
ёмкость в сессиях, не измеренный аппаратный предел. Reference load равен
усечённой до 100 доле успешных SBI-контекстов. HTTP 201 сам по себе не доказывает
завершения PDU Establishment: это дополнительно подтверждается UERANSIM.

Экспериментальная политика использует параметры 3GPP, но не объявляется
единственным алгоритмом, предписанным стандартом. Все SMF в основной серии
обслуживают одинаковые S-NSSAI/DNN/TAI. Выбор ограничен свежим SearchResult.

Пары опытов используют одинаковую последовательность UE replacements с
одинаковым seed. Генератор замкнутый: он ждёт подтверждения операций, поэтому
точные времена поступления между парными прогонами различаются. Первичны
доли успешных созданий, а не абсолютная производительность.

Стандартная полная матрица описана в `scripts/protocol.json`; ограниченная
четырьмя часами пилотная серия отдельно фиксирует фактически выполненные прогоны.
Не называйте запланированные прогоны выполненными и не смешивайте
`results/theory` с измерениями.

Обновление результатов и графиков:

```text
python scripts/test_analysis.py
python scripts/evaluate_article.py
python scripts/plot_article.py
python scripts/render_math.py
python scripts/pdf_article.py
```

Последние три команды требуют matplotlib/Pillow и ReportLab; использованная
среда анализа закреплена в `results/analysis-environment.txt`.
PDF проверен отдельно визуально. Исходник `article/ARTICLE.tex` сохранён;
встроенный компилятор не смог запуститься из-за отсутствия стандартных
каталогов платформы, поэтому компиляция именно этого LaTeX-файла не подтверждена.

Тайм-аут эмулируемого радиоканала поздних опытов — 15 секунд, исходных — 2 секунды.
Heartbeat SMF остаётся равным 1 секунде. Поздняя серия использует четыре
изолированные копии стенда по четыре CPU. В основной эффект включаются только
пары с согласованными режимами; исходные и переходные данные сохраняются.

Патч Open5GS распространяется на условиях AGPL-3.0-or-later исходного проекта.
Для UERANSIM действуют условия лицензии его исходного репозитория.
