# Уточнение пользователем: пять seeds, затем оценка точности

Принято до основных измерений: первый этап — seeds 101–105, две политики,
три нагрузки, всего 30 пар / 60 запусков по 3000 измеряемых назначений.
Прежний предел в 60 пар отменён. Бюджет остаётся 43200 суммарных секунд;
израсходованные и неудачные опыты не обнуляются.

После пяти пригодных пар В КАЖДОЙ ячейке рассчитываются разведочные 95% CI
по bootstrap целых пар (10000 выборок). Целевая полуширина — 1 п.п.
До достижения пяти пар решения о достаточной точности не принимаются.
Неполная серия из-за лимита времени явно обозначается неполной.

Для ячеек с недостаточной точностью заранее выбирается один дополнительный
фиксированный объём: ceil((1.96*s/1п.п.)^2), ограниченный диапазоном 3–5 НОВЫХ
пар с seeds 106–110. Это ориентир планирования по оценённому стандартному
отклонению, а не гарантия покрытия/точности. Размер второй части фиксируется
до её запуска и больше не меняется по промежуточным результатам.
Если расчёт требует больше пяти новых пар, указывается нехватка объёма.
Подтверждающая часть анализируется отдельно; для объединённой адаптивно
собранной выборки обычный bootstrap CI не объявляется валидным 95% интервалом.
При малом числе повторов все интервалы требуют осторожной интерпретации.

После этого приоритет — robustness/cross-implementation, а не новые повторы
ради числа сессий. Эти отдельные исследования не запускаются автоматически
контроллером основной серии.

## Диагностика неудачной подготовки

SWRR: журнал UE содержит успешное установление для UE88 в 12:38:13.070 UTC,
хотя runner сообщил отсутствие подтверждения. Обнаружен дефект: частичная
строка терялась между чтениями. Исправлено накоплением текста. Регрессионный
тест воспроизводит разделённую строку; чужой UE не принимается за нужный.
Границы чтений исходной попытки не записывались, поэтому точный механизм
того ложного тайм-аута нельзя восстановить полностью.

Random: между 12:52:14 и 13:02:37 UTC — пауза, затем массовые radio-link failures.
Windows Kernel-Power 506 в 17:52:01 местного времени: Idle Timeout;
507 в 18:02:34: Input Keyboard. После сна таймеры радиосимулятора истекли.
Контроллер теперь удерживает ES_SYSTEM_REQUIRED на время всей серии и
освобождает запрос после остановки. Настройки питания пользователя не меняются.
Пользовательский принудительный сон этим запросом не запрещается.

Обе неудачные попытки сохранены, исключены из основных данных и учтены в бюджете.
